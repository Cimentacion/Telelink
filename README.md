# TeleLink

Navegador para Android con bloqueo de anuncios que detecta el vídeo de una web y lo manda a la tele por DLNA (Samsung y cualquier tele compatible).

## Uso
1. Abre la web (o comparte un enlace desde otra app hacia TeleLink).
2. Dale al play en la página.
3. Pulsa **Vídeos** y elige cuál mandar. La primera vez busca la tele en la wifi.
4. **Mando**: pausa, saltos, volumen y parar.
5. El candado bloquea los saltos a otros dominios (pop-ups y redirecciones).

## Compilar
Cada push a `main` compila el APK con GitHub Actions y lo publica en **Releases → latest** (`TeleLink.apk`).
